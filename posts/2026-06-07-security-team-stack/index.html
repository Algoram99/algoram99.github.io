The 7 jobs (one-paragraph each)

  1. Vet an MCP server before you install it. An unknown MCP server is a process that can read your filesystem, call your APIs, and execute code on behalf of your agents. Run MCP Poison Scanner on the config to catch tool-poisoning patterns, then MCP Supply Chain Audit on the same config for unverified sources and role overrides, then MCP Server Tester to confirm the server's claimed tool surface actually behaves as documented. Three CLIs, three perspectives, one CI step each.
  2. Ship a new MCP server that won't get flagged by an audit. Use MCP Server Starter Kit to scaffold from a template that's already passed all three audits above (9 tools, 3 servers, 210 tests baked in). Then run MCP Server Tester on every commit to keep the test suite green. Two CLIs, one ship-ready MCP server.
  3. Catch a prompt-leak before a v0 / Next.js / Vercel AI SDK ship. v0 Prompt-Leak Scanner walks the AST and the .env diff for the four patterns that account for the majority of v0-shipped prompt leaks: NEXT_PUBLIC_* secrets baked into client bundles, hardcoded API keys in app/api/ routes, prompt-injection vectors in user-input handlers, and .env files accidentally committed. CI gate with --fail-on high.
  4. Audit an AI agent's config before deployment. Agent Safety Audit covers 36 patterns across 9 categories (tool allowlist, secrets handling, network egress, prompt template, model choice, observability, sandbox, capability grants, recovery). Pair with AgentLint for the 17 best-practice rules that aren't security-critical but prevent config drift. Two CLIs, one production-ready agent config.
  5. Find hardcoded secrets, SQLi, path-traversal, and 12 other anti-patterns. Security Pattern Detector is a fast AST-aware scanner for the 15 most common code-level security anti-patterns. It's not a replacement for a full SAST suite — it's a 5-second pre-commit gate that catches the embarrassing stuff before it leaves your laptop.
  6. Audit a .env file. Env Audit catches the 6 categories of .env mistakes that turn into production incidents: weak defaults (e.g. SECRET=changeme), numeric tokens that look like ports, duplicate keys, empty secrets that pass CI but fail at runtime, plus 2 more. CI gate: env-audit check .env .env.example.
  7. Run a security bounty program without burning hours on scaffolding. Bounty Hunter Kit scaffolds a PoC repo, generates the submission template, and tracks the bounty through the Algora / Huntr / GitHub lifecycle. Pair with Bounty Decision Dashboard for the upstream "is this bounty worth my time?" question.
